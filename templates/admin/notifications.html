Setup Tips
  • Gmail: Enable 2FA → generate an App Password → use it as MAIL_PASSWORD
  • Outlook/Hotmail: Use smtp.office365.com, port 587
  • University SMTP: Contact IT for smtp.ibbul.edu.ng credentials
  • Set MAIL_SUPPRESS_SEND=true in .env to test without sending
